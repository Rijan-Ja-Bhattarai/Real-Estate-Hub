Product roadmap

From scattered
pages to one index.

The frontend is ready for a normalized listing API. The ingestion system below is the next implementation phase.

Source-specific adapters check permitted pages on a schedule, with visible attribution and a direct path back to the original listing.

Addresses, prices and land measurements are normalized, then likely duplicates are grouped without erasing their source history.

A compact read-only API sends the newest version of each property to this interface, along with freshness and source metadata.
